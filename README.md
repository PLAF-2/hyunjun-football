# plaf united

조기축구·풋살 팀 운영을 위한 모바일 중심 웹 앱입니다.

## 주요 기능

- 경기 일정 및 참석 투표
- 공지사항과 팀원 명단
- 팀원별 장점 기록
- 드래그 가능한 전술판
- 출전 선수 추가·제외
- 작성한 전술을 반영하는 감독 모드 미니게임

## 실행

별도의 설치 없이 `index.html`을 브라우저에서 열면 실행됩니다.
